PDF ✅ 完整支持。使用 PDF.js 渲染，文字型、扫描型 PDF 均可。不包含表单提交、注释编辑、嵌入 JavaScript 等交互功能。 按 PDF 真实页面逐页生成，保持原始页面尺寸。
DOCX ✅ 支持常见 Word 文档：正文、列表、表格、内联图片、页眉页脚、脚注尾注。不支持 .doc（旧版二进制格式）。 docx-preview 将 DOCX 转为 HTML 后按 A4 固定宽度切分。分页依赖 Word 写入的 lastRenderedPageBreak 标记，没有该标记的文档会按渲染高度近似切分。
XLSX ✅ 支持单元格内容、基础格式、存储的公式结果。不支持公式重新计算、图表、数据透视表、条件格式的完整视觉还原、宏。 每个工作表生成一张“表格快照”，不按打印分页切分。表格非常宽或非常长时会被压缩，可能丢失列或行。
PPTX ⚠️ 基础支持。使用 pptxjs 将幻灯片转为 HTML，可保留文本框、图片、基础形状。复杂母版、动画、视频、部分背景图可能无法完全还原。 按幻灯片逐页生成，每张幻灯片一页，页面尺寸按 16:9 固定尺寸计算。
TXT ✅ 支持 UTF-8 纯文本。大文件在浏览器中处理，建议单文件不超过数 MB。 按 A4 固定页面尺寸、固定字号分页，每页行数由页面高度决定。
HTML ✅ 支持本地 HTML 文件。脚本不会执行，外部资源（远程图片、样式、字体）可能因浏览器安全策略或网络问题无法加载。 按 A4 固定宽度渲染后切分，页面较长时会产生多页。
图片 ✅ JPG / PNG / WEBP / GIF（静态第一帧）直接预览，不经过“解析”步骤。 保持原始尺寸，按当前格式和质量重新编码输出。

输出图片的“真实文件大小”显示的是 canvas.toBlob 实际生成的 Blob 字节数，不是估算值。 ZIP 按钮上的“约 X MB”为选中页面 Blob 大小之和加 ZIP 头部开销的估算，导出后的提示会显示真实 ZIP 大小。
WEBP 在 Chrome、Edge、Firefox、Safari 14+ 中均支持 canvas.toBlob 编码；若浏览器不支持，toBlob 可能回退为 PNG，文件扩展名仍按 WEBP 命名，建议使用较新版本浏览器。
